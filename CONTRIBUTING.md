# Contributing to Awesome Kitmul

Thank you for your interest in contributing! This list aims to be a comprehensive, well-organized catalog of all Kitmul tools and articles.

## How to Contribute

### Suggest a New Tool

If you'd like to see a new tool added to Kitmul:

1. Open an [issue](../../issues) with the title: `[Tool Suggestion] Your Tool Name`
2. Describe what the tool should do
3. Explain why it would be useful
4. Mention if similar tools exist online (especially ones that require file uploads or payment)

### Report a Broken Link

If you find a broken link in the list:

1. Open an [issue](../../issues) with the title: `[Broken Link] Tool Name`
2. Include the broken URL and which section it's in

### Add a Missing Tool

If a Kitmul tool exists but isn't listed here:

1. Fork this repository
2. Add the tool to the appropriate category in `README.md`
3. Follow the existing format: `| [Tool Name](URL) | Short description |`
4. Submit a pull request

### Improve Descriptions

If you think a tool description could be clearer:

1. Fork this repository
2. Edit the description in `README.md`
3. Keep it concise (one line)
4. Submit a pull request

## Guidelines

- **One tool per row** in the table format
- **Descriptions** should be concise and describe what the tool does, not marketing language
- **Links** should point to the English (`/en/`) version of the tool
- **Categories** should match the existing structure; propose new categories via issues
- **Alphabetical order** is not required; tools are grouped by relevance within each category

## Code of Conduct

Please read our [Code of Conduct](CODE_OF_CONDUCT.md) before contributing.
